# TabC Autocomplete

This repository hosts a macOS input method and Rust engine that work together to deliver low-latency, privacy-preserving autocomplete suggestions.

## Repository layout

```
mac-autocomplete/
├─ engine/               # Rust background daemon
├─ mac/                  # Xcode host app, IME bundle, installer stubs
├─ models/               # Local model artifacts (not checked in)
├─ scripts/              # Helper scripts for development, release, notarization
├─ shared/               # Protocol and header placeholders
└─ README.md
```

### Engine

The Rust engine listens on a UNIX domain socket and accepts JSON messages from the IME. It immediately returns "instant" suggestions generated by a lightweight heuristic engine and follows up with "refined" completions from a stub LLM worker. The runtime is ready to be extended with caching, ranking, and llama.cpp integration.

### macOS IME

The Swift-based IME target contains skeleton implementations for the host app, candidate window, and an `IMKInputController` subclass. The current code focuses on structure and IPC hooks so that the engine can evolve independently.

## Development

* `make engine` — build the Rust engine.
* `make run-engine` — run the engine, binding to `~/Library/Application Support/MacAutoComplete/engine.sock`.
* `scripts/dev_run.sh` — convenience wrapper around the development run command.

The macOS artifacts are placeholders; finalize Xcode projects, entitlements, and installer scripts before distributing to users.
